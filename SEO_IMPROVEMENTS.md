# SEO Improvements for Amporn Tour

## Overview
This document outlines all SEO optimizations implemented for the Amporn Tour website to improve search engine visibility and ranking.

## 1. Technical SEO

### Meta Tags
- **Title Tag**: Optimized with primary keyword "Chiang Mai tours" and brand name
- **Meta Description**: 160 characters, includes target keywords and unique value proposition
- **Canonical URL**: Set to prevent duplicate content issues
- **Robots Meta**: Configured to allow indexing and snippets

### Open Graph & Social Media
- **OG Tags**: Implemented for Facebook, LinkedIn, and other platforms
- **Twitter Card**: Large image card for better social sharing
- **Image Optimization**: High-quality images with descriptive alt text

### Structured Data (JSON-LD)
Implemented comprehensive schema markup:
- **LocalBusiness Schema**: Business information, contact, location
- **Organization Schema**: Company details and contact points
- **Service Schema**: Tour service offerings
- **FAQ Schema**: Common questions about tours and services
